An educational experiment for the Calculus CIE-3 assignment. It is independent of CityPulse and of the GradientBoostingRegressor used by the route planner. Gradient descent is implemented explicitly in NumPy (no prebuilt optimizer), on synthetic travel-time data generated from a known rule plus noise, not on measured travel times.

Mathematics

Model for travel time (minutes) from distance, traffic slowdown and road roughness:

ŷᵢ = wᵀxᵢ + b

Mean Squared Error objective over n samples:

J(w, b) = (1/n) Σᵢ (ŷᵢ − yᵢ)²

Gradients (from the chain rule: d/dw (ŷ−y)² = 2(ŷ−y)·x):

∇wJ = (2/n) Xᵀ(Xw + b·1 − y)
∂J/∂b = (2/n) Σᵢ (ŷᵢ − yᵢ)

Update rules with learning rate α (move against the gradient, the direction of steepest decrease):

wt+1 = wt − α ∇wJ
bt+1 = bt − α ∂J/∂b

J is a convex quadratic, so it has one minimum and gradient descent converges to it if α < 2/λmax(H), where H = (2/n)AᵀA is the Hessian and A = [X, 1]. Features are standardised before training so one α suits all of them. Too small an α converges slowly; too large an α diverges. The run reports the stability limit for the chosen data.
